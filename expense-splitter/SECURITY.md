# Security Policy

## Supported Versions

The following versions of Expense Splitter are currently being supported with security updates:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take the security of Expense Splitter seriously. If you believe you have found a security vulnerability in this project, please report it to us as follows:

1. **Do not open a GitHub issue.** Security issues should be reported privately.
2. Please send an [![Email](https://img.shields.io/badge/Email-D14836?style=flat-square&logo=gmail&logoColor=white)](mailto:malcolm.cephas@gmail.com) with a description of the vulnerability.
3. I'll acknowledge your email to the best of my abilities.

Please include as much information as possible to help us reproduce and understand the issue, including:
- Steps to reproduce the vulnerability.
- Potential impact.
- Any suggested fixes.

Thank you for helping keep Expense Splitter secure!
